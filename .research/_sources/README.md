# Shared Sources

This directory holds durable source registries shared across multiple research topics.

Use it for:

- canonical sources you repeatedly trust or monitor
- research groups, foundations, standards bodies, and maintainer organizations
- important GitHub repositories and discussion venues
- watchlists for sources that should be revisited during future updates

This is research infrastructure, not the main consumption surface.

## remote-topics.md

`remote-topics.md` in this directory is a project-local registry of research conclusions published in external repositories. Add an entry here to make a remote topic available to consumer mode without doing the research locally.

See the `## Remote Topics` section in the deep-research skill for the format and rules.
